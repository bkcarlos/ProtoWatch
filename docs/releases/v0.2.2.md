# ProtoWatch v0.2.2

新增基于 GitHub Releases 的网页更新入口。在左侧“版本更新”检查最新稳定版，按设备平台下载安装包，校验 SHA-256 和程序版本后备份、替换并重启。

- 支持 Linux ARM64 / x86-64、macOS Apple Silicon / Intel、Windows x86-64；运行版本与平台动态显示。
- 安装由用户确认触发，后台下载并显示进度，重连后提示刷新网页。不需要访问令牌。
- 固定官方仓库、限制下载与解压大小，拒绝降级、未知版本、重复安装及不匹配的安装包。替换失败时尝试恢复旧文件。
- Linux 保留文件 capability；若无法恢复则拒绝更新。使用 systemd AmbientCapabilities 的部署可保留抓包权限。

首次启用需手动安装本版本；v0.2.1 及以前没有更新入口。更新需要 GitHub 网络访问和程序目录写权限。重启沿用命令行参数，内存抓包记录及网页临时配置会清空，请先导出。旧二进制备份保留在程序目录，异常时可手动恢复；当前没有启动健康检查后的自动回滚。

Windows 自更新适用于普通进程，不支持 Windows Service 托管场景。macOS / Windows 安装包未做发行者签名或公证。

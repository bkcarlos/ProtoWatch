ProtoWatch 的首个 MVP 发布版：面向 DDS 与 SOME/IP 的被动协议观察台。

### 功能

- DDS：参与者与端点发现、Topic、基础 QoS、消息统计与原始样本预览。
- SOME/IP：TCP / UDP 消息、服务发现、服务实例与提供方筛选、方法 / 事件统计、名称映射与载荷详情。
- TCP：跨包、粘包、有限乱序与重传去重；缺包或重组超限时给出提示。
- 服务端目录加载 PCAP、启动时 `--read`、后台流式解析与进度显示；服务端文件不限制总大小。
- Vue 3 + Element Plus 网页内嵌于单个二进制，运行无需 Node.js、数据库、DDS SDK 或 libpcap。

### 下载与运行

| 平台 | 安装包 |
| --- | --- |
| Linux x86-64 | `proto-watch_v0.2.0_linux-amd64.tar.gz` |
| Linux ARM64 | `proto-watch_v0.2.0_linux-arm64.tar.gz` |
| macOS Intel | `proto-watch_v0.2.0_darwin-amd64.tar.gz` |
| macOS Apple Silicon | `proto-watch_v0.2.0_darwin-arm64.tar.gz` |
| Windows x86-64 | `proto-watch_v0.2.0_windows-amd64.zip` |

解压后运行 `./proto-watch`；Windows PowerShell 使用 `.\proto-watch.exe`。浏览器打开 http://127.0.0.1:8080，在服务端 PCAP 列表中选择工作目录内的抓包文件，或通过 `--pcap-dir` 指定目录。

每份安装包附 SHA-256 文件，`SHA256SUMS` 汇总全部安装包的校验值。5 个平台均经过原生构建、race 测试及编译后二进制的网页 / PCAP 冒烟验证。

### 当前边界

- 实时抓包仅支持 Linux，需要 `CAP_NET_RAW`；macOS 与 Windows 支持网页和离线分析。
- 未压缩 classic PCAP、IPv4；尚不支持 PCAPNG、IP / RTPS 分片及 SOME/IP-TP 重组。
- 保留最近 256 条样本 / 消息，每条原始预览最多 16 KiB；不是完整业务字段解码或全量消息存档。
- TCP 单条消息上限 4 MiB，缺失字节不跳过，连接中途捕获需从可识别消息边界开始。
- macOS / Windows 二进制暂未做发行者签名或公证；真实设备的兼容性与长期负载仍需现场验证。

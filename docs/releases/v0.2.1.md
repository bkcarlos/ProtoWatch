## 界面改进

- 实时采集运行时隐藏服务端 PCAP 文件选择和加载区域；停止采集后重新显示。
- 将浏览器上传和示例入口整理到「其他方式」区域，统一按钮高度、间距与对齐；示例入口采用文字按钮样式。

## 验证与范围

- 前述界面调整已在 Linux 实时采集页面验证。
- 已使用 Cyclone DDS 和 someipy 在独立容器网络中验证真实流量，包括 DDS 发现与复杂样本、SOME/IP 服务发现、多个提供方、UDP 事件及 64 KiB TCP 响应。
- 本版本主要调整界面，未新增协议解码能力。DDS/IP 分片重组、按 IDL/ARXML 解码业务字段仍未实现；原始载荷预览上限仍为 16 KiB。

## 下载

提供 Linux x86-64、Linux ARM64、macOS Intel、macOS Apple Silicon 和 Windows x86-64 单二进制程序。各压缩包附 SHA-256 校验文件及统一的 `SHA256SUMS`。

实时抓包仅支持 Linux；所有平台均支持网页界面和离线 PCAP 分析。
